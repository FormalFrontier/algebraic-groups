# Localized coordinate elimination

Import `AlgebraicGroups.Algebra.LocalizedCoordinateQuotient` for a presentation of a
localized polynomial ring after setting any collection of its variables to zero.

For a commutative ring `K`, arbitrary variable type `σ`, subset `S : Set σ`, and
`f : MvPolynomial σ K`, the map `MvPolynomial.eraseCoordinates K S` is the
existing `MvPolynomial.killCompl` applied to the inclusion `S ↪ σ`. It retains
each `X i` with `i ∈ S` and kills the other variables. The ideal
`MvPolynomial.localizedCoordinateIdeal K S f` in `Localization.Away f` is
generated by the images of the killed variables. The equivalence

```lean
MvPolynomial.localizedCoordinateQuotientEquiv K S f :
  (Localization.Away f ⧸ MvPolynomial.localizedCoordinateIdeal K S f) ≃ₐ[K]
    Localization.Away (MvPolynomial.eraseCoordinates K S f)
```

holds with **no** finiteness, field, domain, nonzero-denominator or nontriviality
assumptions. In particular, if erasure sends `f` to zero, the resulting
localizations and the equivalence still exist (the rings are trivial).

The simp theorems `localizedCoordinateQuotientEquiv_algebraMap` and
`localizedCoordinateQuotientEquiv_symm_algebraMap` describe both maps on the
polynomial coordinates. The forward and reverse retained-variable equations
are `localizedCoordinateQuotientEquiv_coordinate` and
`localizedCoordinateQuotientEquiv_symm_coordinate`; `quotient_killed` gives the
zero relation for any eliminated variable. The maps are obtained from the
universal properties of polynomial evaluation, localization away from a
polynomial, and quotient by the coordinate ideal.

`AlgebraicGroupsTest.Algebra.LocalizedCoordinateQuotient` exercises these equations
over `ℤ`, a denominator erased to zero, empty or all retained variables, and
the polynomial ring with no variables. No matrix or source-specific module is
needed to use this API.
