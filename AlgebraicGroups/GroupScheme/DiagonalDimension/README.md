# Native finite diagonal dimension

`DiagonalCoordinateRing.diagonalIndices` retains the diagonal matrix-entry
variables. `DiagonalCoordinateRing.ideal_eq_localizedCoordinateIdeal` identifies
the *actual* GL Hopf quotient ideal with the ideal generated by all
erased variables. The algebra equivalence
`DiagonalCoordinateRing.localizedPolynomialEquiv` presents that native quotient
as the localization of the retained-variable polynomial ring at the erased
determinant. Both directions identify retained variables with native diagonal
entries; the equivalence requires only a commutative base ring and includes the
zero ring. It uses the generic coordinate-elimination equivalence rather than
replacing the native ring by a disconnected model.

For any field (finite or infinite) and finite matrix index type `ι`,
`AlgebraicGeometry.diagonalCoordinateRing_ringKrullDim` and
`AlgebraicGeometry.diagonalGroupUnderlyingScheme_topologicalKrullDim` compute
the ring and underlying affine scheme dimensions as `Fintype.card ι`, with no
nonempty or infinitude hypotheses. The `diagonalIndicesEquiv` identifies retained
indices with `ι`, while `erasedDeterminant_eval_one` exhibits an explicit
nonvanishing point: retained entries evaluate to one, the other matrix entries
to zero, and the determinant evaluates to one. The dimension proof uses the
supplied-point localization theorem. Consequently empty, singleton and two
indices give dimensions zero, one and two. No dimension formula is asserted
over the zero ring.

Import `AlgebraicGroups.GroupScheme.DiagonalDimension` for the native
presentation and dimensions. From this repository's root, with its pinned
Lean toolchain and exact dependency
graph, fetch the matching mathlib cache before building:

```sh
lake exe cache get
lake build AlgebraicGroups.GroupScheme.DiagonalDimension
lake build AlgebraicGroupsTest.GroupScheme.DiagonalDimension
```

The presentation reuses `AlgebraicGroups.Algebra.LocalizedCoordinateQuotient`, the
dimension calculation reuses
`AlgebraicGroups.Algebra.FinitePolynomialLocalizationDimension`, and the native
coordinate ring/scheme come directly from the existing
`AlgebraicGroups.Algebra.DiagonalCoordinateRing` and
`AlgebraicGroups.GroupScheme.Diagonal` modules.
