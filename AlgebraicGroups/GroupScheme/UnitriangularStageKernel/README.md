# The kernel of a positive unitriangular stage coordinate

Let `K` be any commutative ring, `n r : ℕ` and **`hr : 1 ≤ r`**. Write
`S_r` for the [closed stage](../UnitriangularStages/README.md) and
`J = Matrix.UnitriangularGroup.superdiagonalIndex n r`. The
[coordinate map](../UnitriangularStageCoordinates/README.md) is the actual
group-scheme morphism `S_r → ∏ᶜ (_ : J), Gₐ`; the successor is the existing
closed morphism `S_(r+1) → S_r`.

Import `AlgebraicGroups.GroupScheme.UnitriangularStageKernel` for
`AlgebraicGeometry.unitriangularStageCoordinateMap_isPullback`. This theorem
identifies the square of **underlying schemes over `Spec K`** with the
pullback of the actual product coordinate map along the product's unit
section. Its top arrow is the existing successor, and its left arrow is the
unique morphism to the terminal over-scheme. Thus the successor represents
the scheme-theoretic group-object kernel, rather than merely the kernel on
`K`-points.

The [algebraic module](../../Algebra/UnitriangularStageKernel.lean) proves
`UnitriangularStageCoordinateRing.ideal_succ_eq_sup`: the next ideal is the
sum of the old forbidden-entry ideal and the ideal generated by current
superdiagonal entries. The universal property
`existsUnique_comp_successor` factors an algebra map uniquely through the
successor exactly when these coordinates vanish. Positivity matters:
at `r = 0` a diagonal entry is `1`, not a newly forbidden upper entry.
There is no `r = 0` coordinate map or kernel assertion.

For an arbitrary test scheme, the global-sections/affine-spectrum adjunction
turns a morphism to the current affine stage into an algebra map to global
functions. Commutativity against the *categorical product* forces each
coordinate to vanish. The algebraic universal property gives the unique
successor factor; its base equation supplies the over-scheme structure.
The existing closed immersion ensures uniqueness for arbitrary schemes,
including the zero ring, ranks zero and one, and empty superdiagonals when
`r ≥ n`.

The [ordinary-import client](../../../AlgebraicGroupsTest/GroupScheme/UnitriangularStageKernel.lean)
exercises the pullback, ideal/factorization and boundary cases. With the
repository's pinned toolchain, fetch the matching mathlib cache successfully
before checking the two producers and client:

```sh
lake exe cache get
lake build +AlgebraicGroups.Algebra.UnitriangularStageKernel +AlgebraicGroups.GroupScheme.UnitriangularStageKernel +AlgebraicGroupsTest.GroupScheme.UnitriangularStageKernel
```

The kernel square is not a theorem that the coordinate target is a represented
or sheaf quotient, that the map is surjective or an effective epimorphism,
or that a group-homomorphic section, flatness, smoothness, descent, native
base-change tower or source-level coverage follows. Formal Frontier Agents
developed the proofs; see [credits](../../../CREDITS.md) for roles and reuse.
