# Commutators and derived series of finite unitriangular groups

Import `AlgebraicGroups.GroupTheory.UnitriangularDerivedSeries` to work with the
native group `U = Matrix.UnitriangularGroup (Fin n) R`, where `n : ℕ`,
`R : Type` and `[CommRing R]` (the native matrix API uses a common universe
for the index and coefficient types). Write
`F_d = Matrix.UnitriangularGroup.superdiagonalSubgroup n R d` and use
mathlib's root-namespace `derivedSeries U t`, indexed from
`derivedSeries U 0 = ⊤`. Here `F_d` consists of matrices `g` for which
`(g - 1) i j = 0` whenever `j.val < i.val + d`. In particular,
`F_0 = F_1 = ⊤` and `F_n = ⊥`.

## Public API

- `Matrix.UnitriangularGroup.superdiagonalSubgroup_commutator_eq n R r s hr hs`:
  for `hr : 1 ≤ r` and `hs : 1 ≤ s`, the subgroup commutator
  `⁅F_r, F_s⁆ = F_(r+s)`. The commutator of subgroups is generated by
  element commutators `⁅x,y⁆ = x*y*x⁻¹*y⁻¹`.
- `Matrix.UnitriangularGroup.derivedSeries_eq_superdiagonalSubgroup n R t`:
  the *native* `derivedSeries U t = F_(2^t)` for every `t : ℕ`.
- `Matrix.UnitriangularGroup.superdiagonalSubgroup_eq_bot_iff n R d hd`:
  assuming `[Nontrivial R]` and `hd : 1 ≤ d`, `F_d = ⊥ ↔ n ≤ d`.
- `Matrix.UnitriangularGroup.derivedSeries_eq_bot_iff n R t`:
  assuming `[Nontrivial R]`, `derivedSeries U t = ⊥ ↔ n ≤ 2^t`.

The positive-stage requirement on the commutator equality matters:
`⁅F_0,F_1⁆ = F_2 ≠ F_1` in `U = UT₂(ZMod 2)`. The weak inequality in
the stopping criteria is essential: `F_n = ⊥`, including for `n = 1`;
strict `n < d` would be false at `d = n`. The stage criterion needs `d ≥ 1`;
`F_0 = ⊤ = ⊥` in dimension one despite `1 ≰ 0`. The two series equalities
hold without `[Nontrivial R]`, including dimensions zero and one,
characteristic two, nonreduced rings, and the zero ring. In a subsingleton
ring the whole group is trivial and the derived series is already bottom at
`t = 0` in every dimension, so its numerical stopping criterion does not
apply there.
